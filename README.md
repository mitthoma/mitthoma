## How I work with agents

- **Outcomes over demos.** An agent that saves a team 10 hours a week beats one that looks good in a video.
- **Evals before scale.** If I can't measure it, I don't ship it.
- **Boring reliability.** Timeouts, retries, human-in-the-loop gates, and audit logs are the product, not the afterthought.
- **The client is in the room.** Scoping an underspecified problem with a non-technical stakeholder is half the job.
